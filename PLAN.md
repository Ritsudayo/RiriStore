# PLAN.md

## 1. Этапы реализации и зависимости

**Этап 0. Инфраструктура (DONE)**
- Next.js 15 + TypeScript + Tailwind.
- Prisma + SQLite.
- Git + GitHub (репозиторий Ritsudayo/RiriStore).
- Система памяти агента (AGENTS.md, PRODUCT.md, PLAN.md, TASKS.md, docs/agent/).
Зависимости: нет.

**Этап 1. Главная страница**
- Header: логотип по центру, профиль справа, корзина и избранные - слева.
- Блок «О магазине» (кратко про RiriStore) + баннер с фото
- Сетка категорий (4 карточки).
- Блок «Объявления» (Announcement).
- Footer с соцсетями.
Зависимости: Этап 0.

**Этап 2. Каталог и категории**
- Страница /catalog.
- Бургер-меню слева со списком категорий.
- Сетка товаров (3-4 в ряд).
- Фильтр по цене.
- Пагинация.
- Страница /catalog/[category-slug] — товары категории.
Зависимости: Этап 1, БД Prisma.

**Этап 3. Карточка товара**
- Страница /product/[id].
- Галерея фото (несколько ракурсов).
- Название, описание, цена.
- Характеристики (размер, длина, материал, срок изготовления).
- Кнопка «В корзину» (крупная).
- Кнопка «В избранное» ❤️.
- Блок «Из той же категории».
- Хлебные крошки.
Зависимости: Этап 2.

**Этап 4. Авторизация**
- Регистрация по email/паролю.
- Логин.
- NextAuth.
- Хэширование паролей (bcrypt).
- Защита роутов (профиль, админка).
Зависимости: Этап 0.

**Этап 5. Корзина и оформление заказа**
- Состояние корзины (Zustand или React Context).
- Страница /cart.
- Страница /checkout — форма (ФИО, телефон, email, ПВЗ).
- Создание Order в БД.
- Страница «Спасибо за заказ».
- Заявка падает продавцу (Telegram-бот или email).
Зависимости: Этапы 3, 4.

**Этап 6. Профиль и заказы**
- Страница /profile.
- Личные данные: ник, email, аватар.
- Смена пароля.
- Список заказов со статусами.
- Просмотр содержимого заказа.
- Плашка «Помощь по заказам».
Зависимости: Этапы 4, 5.

**Этап 7. Админка**
- Страница /admin (только для role=admin).
- Список товаров + кнопки добавить/редактировать/удалить.
- Форма товара: название, описание, цена, категория, фото, материалы.
- Список категорий + CRUD.
- Список заказов + изменение статуса.
- Управление объявлениями.
Зависимости: Этапы 2, 5.

**Этап 8. Готический дизайн**
- Палитра: викторианская готика (тёмный фон + фиолетовый + серебряный).
- Шрифты: Cinzel/Cormorant для заголовков, Inter для текста.
- Орнаменты, рамки, текстуры.
- Анимации (hover, свечение).
Зависимости: все предыдущие.

**Этап 9. Деплой**
- Vercel.
- База данных — Postgres (Vercel Postgres или Supabase).
- Домен (если купишь).
Зависимости: всё.

## 2. Архитектура и ограничения

- **Frontend + Backend**: Next.js App Router (единый проект).
- **API**: Next.js Route Handlers (`/app/api/...`).
- **БД**: SQLite (dev) → Postgres (prod).
- **ORM**: Prisma.
- **Авторизация**: NextAuth с credentials provider.
- **Стили**: Tailwind CSS.
- **Состояние**: React Context + Zustand (для корзины).
- **Фото товаров**: пока локально в `public/uploads/`, потом — Vercel Blob / Cloudinary.

## 3. Модули

**Backend (Route Handlers):**
- `api/auth` — регистрация, логин.
- `api/products` — CRUD товаров.
- `api/categories` — CRUD категорий.
- `api/cart` — корзина.
- `api/orders` — заказы.
- `api/favorites` — избранное.
- `api/announcements` — объявления.
- `api/upload` — загрузка фото.

**Frontend (страницы):**
- `/` — главная.
- `/catalog` — каталог.
- `/catalog/[slug]` — категория.
- `/product/[id]` — товар.
- `/cart` — корзина.
- `/checkout` — оформление.
- `/profile` — профиль.
- `/favorites` — избранное.
- `/admin` — админка.
- `/login`, `/register` — авторизация.

**Компоненты:**
- Header, Footer, ProductCard, CategoryCard, Gallery, CartItem, OrderCard, AdminForm и т.д.

## 4. Стратегия тестирования

- **Ручные проверки** — после каждой задачи.
- **E2E сценарии** (ручные):
  1. Регистрация → логин → добавить в корзину → оформить заказ → увидеть в профиле.
  2. Админ добавляет товар → он появляется в каталоге.
  3. Добавить в избранное → увидеть на странице избранного.
  4. Мобильная версия — проверить все страницы.
- **Тесты** (потом, если время будет): Vitest для утилит, Playwright для E2E.

## 5. Критерии завершения этапов

- **Этап 1**: главная страница полностью свёрстана, все блоки на месте.
- **Этап 2**: каталог открывается, фильтр работает, пагинация работает.
- **Этап 3**: карточка товара открывается, галерея листается, «в корзину» работает.
- **Этап 4**: можно зарегаться, войти, выйти.
- **Этап 5**: заказ создаётся и попадает в БД.
- **Этап 6**: заказы видны в профиле.
- **Этап 7**: админ может добавить товар.
- **Этап 8**: сайт выглядит готично.
- **Этап 9**: сайт доступен по ссылке.

## 6. Риски и откат

| Риск | Митигация |
|------|-----------|
| Долгая разработка | Итерации, MVP первым |
| Сложности с NextAuth | Если будет тупить — упрощённая авторизация |
| Проблемы с оплатой | Первые заказы — вручную |
| Стиль готики перегружен | Тёплые тона, не пугать, тестировать на друзьях |
| Потеря кода | Git + GitHub после каждой задачи |

**Общий принцип отката:** каждая задача = отдельный коммит. Если что-то сломалось — `git reset --hard HEAD~1` или `git revert`.
