## Правила обновления

- `TASKS.md` конкретизирует этапы из `PLAN.md`, но не дублирует весь стратегический план.
- **Агент сам добавляет новую строку `T-XXX` перед началом каждой задачи.**
- **ID задачи генерируется автоматически: следующий по порядку после последней (T-001, T-002, ...).**
- Во время выполнения агент пишет в собственный timestamp-файл `docs/agent/tasks/T-XXX/`.
- Центральный файл обновляет один координатор после проверки `git diff` и тестов.
- Прогресс указывается как `выполненные критерии / всего`.
- Поле `Последний файл выполнения` указывает на самый свежий проверенный файл в `docs/agent/tasks/<TASK-ID>/`.
